01 · FeaturesTính năng

Record, run, reportGhi, chạy, báo cáo

From a quick smoke test to data-driven batch runs across hundreds of rows. Từ một lần smoke test nhanh đến chạy hàng loạt theo dữ liệu trên hàng trăm dòng.

Record in one clickGhi lại bằng một click

Clicks and typing become editable, reorderable steps — 17 action types, from hovers to file uploads. Click và nhập liệu thành các bước sửa và sắp xếp lại được — 17 loại hành động, từ hover đến tải file.

Playback that keeps goingPhát lại không đứt quãng

Loop, sequence or schedule runs that carry on through iframes, page reloads, native dropdowns and file pickers. Chạy lặp, nối tiếp hoặc theo lịch, vẫn chạy tiếp qua iframe, tải lại trang, dropdown gốc và hộp chọn file.

Assertions, verdicts & bug reportsAssertion, kết quả & bug report

Assert what the page should show, get a Passed / Failed / Broken verdict for every run and a bug report to paste. Kiểm tra trang hiển thị đúng chưa, nhận kết quả Passed / Failed / Broken cho mỗi lần chạy và bug report sẵn để dán.

Variables & logicBiến & logic

Static, random, pick-from-list and fallback variables, Read DOM, conditions and switch branches. Biến tĩnh, ngẫu nhiên, chọn từ danh sách và dự phòng, Read DOM, điều kiện và rẽ nhánh switch.

CSV data-driven runsChạy theo dữ liệu CSV

Upload a CSV and its headers become ${variables}. One run per row, results exported to Excel, HTML or ZIP. Tải CSV lên, tiêu đề cột thành ${variables}. Mỗi dòng một lần chạy, kết quả xuất ra Excel, HTML hoặc ZIP.

Code exportXuất code

Turn a scenario into a JS bookmarklet, Selenium Python or pytest, Playwright Test, Robot Framework or Selenium Java test. Chuyển kịch bản thành JS bookmarklet, Selenium Python hoặc pytest, Playwright Test, Robot Framework hoặc Selenium Java.

02 · ToolsCông cụ

Test design & everyday toolsThiết kế test & công cụ hằng ngày

Design SQL test cases, roll back test data, and keep screenshots and notes in one place. Thiết kế test case SQL, hoàn tác dữ liệu test, giữ ảnh chụp và ghi chú ở cùng một nơi.

Screenshots & image toolsẢnh chụp & công cụ ảnh

Six capture modes, from the visible area to a whole window — plus an image editor, watermark and image diff. Sáu chế độ chụp, từ vùng đang thấy đến cả cửa sổ — kèm trình sửa ảnh, watermark và so sánh ảnh.

Highlights by URL patternĐánh dấu theo mẫu URL

Highlight text on any page in five colours, with notes — restored on every visit, grouped by URL pattern. Tô sáng chữ trên mọi trang với 5 màu, kèm ghi chú — tự hiện lại mỗi lần truy cập, gom theo mẫu URL.

SQL Test Case Designer

Paste a SQL query and get EP/BVA, decision-table, NULL and JOIN test cases, with fixture data. Dán câu SQL để nhận test case EP/BVA, bảng quyết định, NULL và JOIN, kèm dữ liệu mẫu.

DB Test Session & Rollback

Every change you make to test data in Adminer is recorded — roll it all back in one click, SQL shown first. Mọi thay đổi dữ liệu test trong Adminer đều được ghi lại — hoàn tác hết bằng một click, xem trước câu SQL.

Hotkeys, backup & settingsPhím tắt, sao lưu & cài đặt

Configurable hotkeys, import/export and full backup, and per-category notifications. Phím tắt tuỳ chỉnh, nhập/xuất và sao lưu toàn bộ, thông báo bật/tắt theo từng loại.

04 · PrivacyRiêng tư

Your tests stay in your browserDữ liệu test ở lại trong trình duyệt của bạn

No account and no analytics. Here is what Pocket QA keeps and the one request it makes. Không tài khoản, không analytics. Đây là những gì Pocket QA lưu và yêu cầu mạng duy nhất nó gửi đi.

Stored on this computerLưu trên máy này

Scenarios, variables, CSV data, screenshots and run results live in Chrome's local extension storage. Nothing is uploaded. Kịch bản, biến, dữ liệu CSV, ảnh chụp và kết quả chạy nằm trong bộ nhớ cục bộ của tiện ích trên Chrome. Không có gì được tải lên.

Settings can syncCài đặt có thể đồng bộ

Hotkeys, screenshot naming and notification switches use Chrome's sync storage, so they follow you to your other devices if Chrome Sync is on. Phím tắt, cách đặt tên ảnh chụp và các công tắc thông báo dùng bộ nhớ đồng bộ của Chrome, nên theo bạn sang thiết bị khác nếu bật Chrome Sync.

One request out, once a dayMột yêu cầu mạng mỗi ngày

Besides Chrome's own update check, Pocket QA reads a small version file from kt-hg.github.io so a broken release can be stopped. It carries none of your data. Ngoài lần kiểm tra cập nhật của chính Chrome, Pocket QA đọc một file phiên bản nhỏ từ kt-hg.github.io để có thể dừng một bản phát hành lỗi. Yêu cầu này không mang dữ liệu nào của bạn.

DB rollback stays on your AdminerRollback DB chỉ chạy trên Adminer của bạn

Undo SQL goes only to the Adminer page you are working in, over your existing session. Câu SQL hoàn tác chỉ được gửi tới trang Adminer bạn đang làm việc, qua phiên đăng nhập hiện có.

05 · PermissionsQuyền

Why it asks for each permissionVì sao cần từng quyền

Every permission in the extension's manifest, and what Pocket QA uses it for. Mọi quyền khai báo trong manifest của tiện ích và Pocket QA dùng chúng vào việc gì.

<all_urls>
Read and change data on all websites — to record, replay and screenshot any site you test.Đọc và thay đổi dữ liệu trên mọi trang web — để ghi, phát lại và chụp ảnh trang bạn đang test.
tabs
Find the tab you record or play on, navigate it during a run, and set its zoom for captures.Tìm tab đang ghi hoặc đang phát lại, chuyển trang trong lúc chạy và đặt mức zoom khi chụp.
scripting
Put the recorder, the player and highlights into the page.Đưa bộ ghi, bộ phát lại và phần đánh dấu vào trang.
storage
Keep your scenarios, variables and settings (see Privacy).Lưu kịch bản, biến và cài đặt (xem phần Riêng tư).
debugger
Trusted clicks on native dropdowns, file uploads, Run JS steps, and full-page and element screenshots.Click tin cậy trên dropdown gốc, tải file lên, bước Run JS, chụp cả trang và chụp phần tử.
downloads
Save screenshots, exported code, run results and SQL test cases.Lưu ảnh chụp, code đã xuất, kết quả chạy và test case SQL.
alarms
Scheduled runs, keeping long runs alive, and the daily update check.Chạy theo lịch, giữ cho lần chạy dài không bị dừng và kiểm tra cập nhật hằng ngày.
windows
Window screenshots, and bringing the right window forward during a run.Chụp cửa sổ và đưa đúng cửa sổ lên trước trong lúc chạy.
notifications
Run results, failures and update notices — each category can be switched off.Thông báo kết quả, lỗi và cập nhật — tắt được từng loại.
desktopCaptureoptionaltuỳ chọn
Asked for only when you capture a whole window; nothing else needs it.Chỉ hỏi khi bạn chụp cả cửa sổ; không tính năng nào khác cần đến.
06 · FAQHỏi đáp

Questions, answeredCâu hỏi thường gặp

Is Pocket QA free?Pocket QA có miễn phí không?

Yes, completely — no paid tier and no account.Có, hoàn toàn miễn phí — không có gói trả phí, không cần tài khoản.

Do I need to write code?Có cần biết viết code không?

No. Record a flow once and replay it from the popup. Code export is there for when you want the same test in Selenium, Playwright, Robot Framework or Java.Không. Ghi lại một luồng một lần rồi phát lại từ popup. Tính năng xuất code dành cho khi bạn muốn có cùng bài test đó trong Selenium, Playwright, Robot Framework hoặc Java.

Which browsers does it run on?Chạy trên trình duyệt nào?

Chrome 109 or newer.Chrome 109 trở lên.

Why does Chrome say Pocket QA "started debugging this browser"?Vì sao Chrome báo Pocket QA đang gỡ lỗi (debug) trình duyệt?

Chrome shows that bar whenever an extension uses its debugger API, which Pocket QA does for the steps listed under debugger above. It detaches when the run ends, and the bar goes away.Chrome hiện thanh báo đó mỗi khi một tiện ích dùng debugger API; Pocket QA dùng nó cho các bước nêu ở quyền debugger phía trên. Khi lần chạy kết thúc, tiện ích ngắt kết nối và thanh báo biến mất.
